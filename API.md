# CyberGuardian AI — API Route Reference

CyberGuardian AI provides a RESTful API powered by FastAPI. Full interactive Swagger UI documentation and OpenAPI specifications are available at `/docs` and `/api/v1/openapi.json` when running in development mode.

---

## Endpoint Summary

### Authentication (`/api/v1/auth`)
- `POST /api/v1/auth/register` — Register a new user and organization workspace
- `POST /api/v1/auth/login` — Authenticate user credentials and return JWT OAuth2 bearer token
- `GET /api/v1/auth/me` — Retrieve current authenticated user profile

### Assets (`/api/v1/assets`)
- `GET /api/v1/assets/` — List all registered target assets for current organization
- `POST /api/v1/assets/` — Register a new target domain asset
- `POST /api/v1/assets/{id}/verify` — Trigger domain ownership verification check (DNS TXT / HTML file)

### Security Scans (`/api/v1/scans`)
- `POST /api/v1/scans/` — Initiate a security scan (`vulnerability`, `pentest`, or `strix`) against a verified asset
- `GET /api/v1/scans/` — List security scans for current organization
- `GET /api/v1/scans/{id}` — Get scan status and summary details
- `GET /api/v1/scans/{id}/findings` — Retrieve findings generated by a scan

### Findings (`/api/v1/findings`)
- `GET /api/v1/findings/` — Query security findings across organization assets
- `PATCH /api/v1/findings/{id}/status` — Update finding status (`open`, `accepted_risk`, `false_positive`)

### Bug Bounty & Vulnerabilities (`/api/v1/bounty`)
- `GET /api/v1/bounty/programs` — List public & workspace bug bounty programs
- `POST /api/v1/bounty/programs` — Create a new bug bounty program
- `POST /api/v1/bounty/reports` — Submit a vulnerability report (Researchers)

### Admin System Health & Diagnostics (`/api/v1/admin/system-health`)
- `GET /api/v1/admin/system-health/run` — Run live automated test suite & platform diagnostic checks (Admin only)

### Public Trust Badge (`/api/v1/badge`)
- `GET /api/v1/badge/{domain}/svg` — Embeddable SVG trust badge (Grade A-F) for verified completed scan assets
